# Net Zero Metrics

Calculate Net Zero Carbon metrics in accordance with [UK Net Zero Carbon Building Standard Pilot Version (Sept 2024)](https://www.nzcbuildings.co.uk/pilotversion). See the [docs](https://maxfordham.github.io/netzero-metrics/) for more information.


## Develop

[Install `pixi`](https://pixi.sh/latest/)

```console
pixi run list #  list tasks
pixi run tests #  run tests
```
