Reference Data

The netzero_metrics package relies on data collated by UK Net Zero Carbon Building Standard Pilot Version (Sept 2024), TableOE-1 & TableOE-2.

Warning

To enable comparison across types, currently the only metrics being consider are those measured in Kwhr/m2(GIA)/yr.
