netzero-metrics

A python package for analysing the performance of a Construction Project compared to UK Net Zero Carbon Building Standard Pilot Version (Sept 2024).

Caution

Currently the scope of this package is limited to Operational Energy Targets defined by UKNZCB based on end use areas only. The intention is that over-time other UKNZCB metrics will be added.
